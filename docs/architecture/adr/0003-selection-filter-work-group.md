# ADR-0003: Selection, Filter и Work Group различны

- **Status:** Accepted
- **Date:** 2026-08-28

## Context

Ручной выбор, фильтр видимости и сохранённая научная группа похожи визуально, но имеют разные жизненные циклы и последствия.

## Decision

Selection — эфемерное множество Analysis IDs. Filter — обратимое правило видимости в конкретном контексте. Work Group — именованный сохранённый снимок Analysis IDs с автором и временем. Ни одна операция не преобразует их друг в друга неявно.

Selection синхронизируется между таблицей и всеми графиками. Простой focus/hover не меняет Selection. Сохранение Work Group является отдельной командой.

## Consequences

UI показывает разные действия и статусы. Persistence хранит Work Group и сохранённые фильтры/спецификации, но не восстанавливает эфемерный Selection как будто это группа.
