# ADR-0004: Provenance и неизменность исходных измерений

- **Status:** Accepted
- **Date:** 2026-08-28

## Context

Научный результат должен позволять восстановить источник, преобразование и допущения. Молчаливая правка Measurement разрушает воспроизводимость.

## Decision

Исходный файл и импортированное Measurement не меняются расчётом или интерпретацией. Исправление создаёт аудируемую ревизию с прежним и новым значением, причиной и автором. Derived Value хранит входы, правило, параметры и версию алгоритма. Import Batch хранит SHA-256 файла, лист, строку и отчёт преобразований.

## Consequences

Хранение содержит больше метаданных и ревизий, но любой график и экспорт можно проследить до исходных данных.

Экспорт отбора XLSX читает один снимок SQLite по переданным Analysis ID. Книга хранит состав отбора в исходном порядке, SHA-256 и координаты источника, отпечаток рецепта и исходные токены с единицами, статусом и пределом обнаружения. Текст исходника записывается как текст Excel, включая токены, начинающиеся с `=`. Недоступный Analysis ID отменяет операцию целиком. Результат записывается в новый файл без перезаписи.

Черновик хранит стабильный Measurement ID, прежний токен, предложенное значение и SHA-256 на момент импорта. Новые импорты запоминают путь к исходному файлу отдельно от рабочей копии. Проверка перечитывает этот файл и фиксирует конфликт, SHA-256 и наблюдаемый токен XLSX. Для прежней управляемой копии без сохранённого исходного пути проверка сообщает, что исходник недоступен.

Команда записи требует автора и причины. В Windows она удерживает исключительный доступ к исходному XLSX, сверяет SHA-256 и прежний токен, записывает резервную копию и подготовленную операцию до изменения файла. При ошибке записи исходные байты восстанавливаются под той же блокировкой. Завершённая операция хранит контрольные суммы, ячейку и путь к копии. Импортированный Measurement остаётся неизменным. Первая реализация поддерживает правку существующего числового значения в XLSX без формул и цифровых подписей. Если процесс был прерван посреди записи и исходный файл отличается от обеих контрольных сумм, восстановление выполняется из указанной копии.
