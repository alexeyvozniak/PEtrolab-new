# ADR-0004: Provenance и неизменность исходных измерений

- **Status:** Accepted
- **Date:** 2026-08-28

## Context

Научный результат должен позволять восстановить источник, преобразование и допущения. Молчаливая правка Measurement разрушает воспроизводимость.

## Decision

Исходный файл и импортированное Measurement не меняются расчётом или интерпретацией. Исправление создаёт аудируемую ревизию с прежним и новым значением, причиной и автором. Derived Value хранит входы, правило, параметры и версию алгоритма. Import Batch хранит SHA-256 файла, лист, строку и отчёт преобразований.

## Consequences

Хранение содержит больше метаданных и ревизий, но любой график и экспорт можно проследить до исходных данных.
