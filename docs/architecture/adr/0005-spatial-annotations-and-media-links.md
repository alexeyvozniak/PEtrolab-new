# ADR-0005: Spatial Annotation и Media Link

- **Status:** Accepted
- **Date:** 2026-08-28

## Context

Анализы и фотографии нужно связывать с очень маленькими зонами шлифа при большом увеличении, не смешивая изображение, точку и Analysis.

## Decision

Point, Rectangle и Square являются вариантами Spatial Annotation и сохраняются в исходных координатах изображения независимо от zoom. Analysis–Annotation и Media–Annotation — отдельные обратимые связи. Фокус на аннотации не меняет Selection; для этого есть явная команда «Добавить связанные анализы к отбору».

При точном увеличении UI запрашивает видимый прямоугольник оригинала и восстанавливает фокус по сохранённой Spatial Annotation. При проверке плана импорта сервис использует одинаковое числовое представление координат, переданных как `36` и `36.0`. Изменение величины меняет отпечаток плана.

Предпросмотр снимка возвращает ID связанной Analytical Point и её физического Sample. Инспектор ищет активные Analysis в этом Sample. `analytical_point.link.set` принимает один `analysis_id` для добавления или снятия связи и массив `analysis_ids` для пакетного добавления. В пакетной операции проверка принадлежности, запись связей и запись журнала проходят в одной транзакции. Ошибка в любой строке отклоняет весь пакет.

## Consequences

Одна область может иметь несколько методов анализа и несколько медиафайлов. Снятие связи не удаляет Analysis, Spatial Annotation или Media Asset.
