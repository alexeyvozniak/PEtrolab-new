# ADR-0006: Стабильная легенда и обратимая видимость точек

- **Status:** Accepted
- **Date:** 2026-08-28

## Context

Пользователь заранее настраивает легенду при построении. Текущий ручной Selection должен быть заметен, но не уничтожать смысл цветов и маркеров. Единичные выбросы иногда требуется убрать из диапазона осей без удаления данных.

## Decision

Legend Definition сохраняется в Plot Specification. Selection рисуется отдельным зелёным контуром поверх базового маркера или линии. Plot Visibility хранит обратимый список скрытых Analysis IDs. Скрытые точки исключаются из autoscale и hit testing, но остаются в данных и Selection.

## Consequences

Отрисовка имеет отдельные слои base series, visibility mask и selection overlay. Команда скрытия не является QC-операцией и не меняет Scientific Core.
