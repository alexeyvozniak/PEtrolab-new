# ADR-0006: Стабильная легенда и обратимая видимость точек

- **Status:** Accepted
- **Date:** 2026-08-28

## Context

Пользователь заранее настраивает легенду при построении. Текущий ручной Selection должен быть заметен, но не уничтожать смысл цветов и маркеров. Единичные выбросы иногда требуется убрать из диапазона осей без удаления данных.

## Decision

Legend Definition сохраняется в Plot Specification. Selection рисуется отдельным зелёным контуром поверх базового маркера или линии. Plot Visibility хранит обратимый список скрытых Analysis IDs. Скрытые точки исключаются из autoscale и hit testing, но остаются в данных и Selection.

Команды скрытия и возврата записывают изменённые Analysis ID и идентификатор текущего сеанса просмотра в Operation Journal. Отмена по записи проверяет текущий список и более поздние изменения видимости для тех же ID в этом сеансе. Обратное действие возвращает только эти ID, а исходная запись получает состояние «отменена». Открытие сохранённой раскладки начинает новый сеанс просмотра. Сама раскладка сохраняет свой список скрытых точек.

Исключение источника в «Поиске» и в легенде меняет один фильтр диаграмм по точному Source ID. Фильтр применяется на всех панелях и сохраняется в раскладке. Точки источника остаются доступны в таблицах, а состав Selection и состояние отдельных скрытых Analysis ID сохраняются.

Гистограмма получает границы и состав интервалов из Python. Сегменты источников сохраняют цвета легенды. Клик или Enter применяет выбранное действие отбора к точным Analysis ID сегмента, а при прямоугольнике и лассо учитывается центр сегмента. Версия разбиения хранится в раскладке, шаблоне и снимке публикации.

## Consequences

Отрисовка имеет отдельные слои base series, visibility mask и selection overlay. Команда скрытия не является QC-операцией и не меняет Scientific Core.
