# ADR-0009: Векторный экспорт, Publication Package и Plot Layers

- **Status:** Accepted
- **Date:** 2026-08-29

## Context

Исследователю требуется быстро выгружать любой готовый материал и отдельно собирать большие журнальные комплекты. SVG должен редактироваться в CorelDRAW без PowerClip-реликтов. Для сравнения массивов нужны независимо оформляемые слои и воспроизводимые поля.

## Decision

Быстрый export service доступен из владельца материала. Publication Package является отдельным агрегатом для упорядоченного набора Export Artifacts и журнала. Corel-safe SVG использует плоские редактируемые группы и запрещает clipPath, mask, foreignObject и растеризацию векторных примитивов; валидатор проверяет профиль до записи.

Диаграммы передают одному сервису проверяемый SVG снимка отображённых осей, панелей, точек и полей. Tauri выбирает имя и место записи. Python проверяет SVG, сохраняет редактируемый PDF со встроенным DejaVu Sans или растеризует тот же PDF в PNG/TIFF с выбранным dpi. Экспорт пишет новый файл атомарно. [Связка Svglib и ReportLab](https://github.com/deeplook/svglib), [API PDFium](https://pypdfium2.readthedocs.io/en/stable/python_api.html).

Прямое добавление в публикацию создаёт материал `plot_capture` в черновике открытого приложения. Материал связывает SVG и параметры экспорта с отпечатком проекции каждой панели и фиксирует входные Analysis ID. При сборке ZIP сервис повторно сверяет проекции и сохраняет снимок панелей с осями, слоями, видимостью и участниками. CSV значений осей добавляется по выбору пользователя. Исходные токены измерений сохраняются в supplementary data.

Снимок `selection_table` фиксирует порядок Analysis ID и отпечаток XLSX. Снимок `media_capture` фиксирует отпечатки источника и копии, выбранную разметку и связи с точками и областями. Подготовка и запись пакета повторно проверяют отпечатки. Для XLSX нормализуются даты внутри книги, чтобы повторная сборка из тех же данных давала те же байты.

Материал `formula_run` включает неизменяемую запись метода, Measurement ID, отпечаток входа и Derived Values. Пакет добавляет `data/derived_values.csv` с ID расчёта, версиями, единицами и отпечатками отдельно от исходной `data/measurements.jsonl`. Подготовка и запись повторно проверяют актуальность расчёта. Устаревший запуск блокирует сборку.

Plot Specification содержит упорядоченные Plot Layers. Каждый слой хранит точный набор Analysis ID, z-order, point style/opacity/visibility и опциональный Field с методом и параметрами. Plot Visibility исключает Analysis из входа Field; скрытие маркеров слоя не исключает.

Научный контракт расчётной оси версии 1 хранит `calculation` с операцией `sum` или `ratio` и упорядоченным списком полей Measurement. Каждый операнд указывает поле, единицу, метод и аналитический набор. Сумма сохраняет домен, а ppm и ppb приводятся к заявленной единице. Отношение двух концентраций одного домена безразмерно. Тройная проекция сумм использует неперекрывающиеся компоненты одного домена. Для трёх отношений версии 1 требуется общий знаменатель. FeOt можно использовать как измеренный вход при явно сохранённой форме FeOt. Автоматического перевода Fe₂O₃ или расчёта Fe²⁺/Fe³⁺ в этой версии нет.

Проекция фиксирует Measurement ID, исходные токены, единицы, форму железа и причины исключения. Снимок публикации сохраняет определения и доказательства проекции, а раскладка хранит версии определения и операнды. Перенос расчётных осей через Analysis Template использует сопоставление операндов и явную привязку новых формул по ADR-0010.

Ось `formula` указывает поле `apfu.*`, версию и отпечаток метода и точные ID Calculation Run. `plot_data.catalog` возвращает группы сохранённых формул при `include_formula: true`. Для каждого анализа выбирается один запуск, и все три вершины APFU используют одинаковый набор запусков и единую основу. Бинарная панель может сопоставить APFU с измеренным полем. Число берётся из сохранённого Derived Value после той же проверки актуальности, которую использует открытие формулы. Проекция фиксирует ID Derived Value и Measurement, основу нормировки и причину исключения устаревшего или неполного расчёта. Публикация сверяет отпечаток проекции повторно.

## Consequences

Одиночный экспорт не требует создания пакета. Большой пакет воспроизводим и проверяем. Сравнительные поля можно восстановить, а Selection остаётся независимым верхним оверлеем.
