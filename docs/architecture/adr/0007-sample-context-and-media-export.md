# ADR-0007: Полевой контекст Sample и экспорт Media Asset

- **Status:** Accepted
- **Date:** 2026-08-29

## Context

Карточка образца должна сохранять не только лабораторные связи, но и полевой смысл: где образец отобран и хранится, какие заметки и фотографии обнажения к нему относятся. Одно и то же изображение требуется выгружать как чистый источник либо как публикационную копию с аннотациями.

## Decision

Sample хранит структурированный полевой контекст отдельно от физического места хранения. Sample Notes являются отдельными записями с автором и временем. Полевые фотографии, изображения ручного образца и микроскопические снимки остаются Media Assets с явным типом.

Миграция 21 разрешает пустой `thin_section_id` для полевого фото и снимка ручного образца. Проекты версии 20 сохраняют прежние принадлежности, Spatial Annotations и Media Links. План импорта версии 3 хранит `thin_section_name: null` как явное назначение на Sample без пространственных размещений. Планы 1 и 2 сохраняют прежнюю семантику. Обзор, экспорт и архив проекта читают такие Media Assets напрямую по Sample.

Табличный импорт связывает выбранные Analysis с физическим Sample только по явному решению для конкретных preview ID. Пользователь выбирает существующий Sample по ID или задаёт уникальное имя нового Sample в проекте. Одинаковые обозначения в исходных файлах остаются в provenance. Создание нового Sample и запись назначений происходят в транзакции импорта.

Исходный Media Asset неизменяем. `export_media_original` создаёт файл из исходных пикселей без графических слоёв. `render_media_export` создаёт новый производный файл и получает явный набор Point, подписей, Rectangle/Square, масштаба, легенды и параметров рендера. Оба результата ссылаются на источник и сохраняют provenance.

Для PNG пользователь может выбрать конкретные `annotation_ids`. Легенда считает только выгруженные точки и области. Линейка по умолчанию использует пиксели оригинала. Физическая шкала требует явно введённой пары «горизонтальная длина и число пикселей на исходном изображении». Расчёт выполняется в Python. PNG сохраняет исходную пару, единицу, длину нарисованной линейки и SHA-256 изображения. Эта калибровка применяется к конкретному экспорту. Если панель легенды и линейки не помещается на снимке или перекрывает выбранную метку, область либо подпись, она размещается под снимком без изменения его пиксельной геометрии.

`media.export_batch` получает точный список Media Asset ID и общие параметры слоёв либо `null` для оригиналов. Рендер использует аннотации каждого изображения и линейку в его исходных пикселях. Физическая калибровка и выбор отдельных аннотаций выполняются при экспорте одного изображения. ZIP включает файлы и `manifest.json` с исходными именами, ID, путями, SHA-256 источников и результатов. Сборка завершается во временном каталоге и записывает ZIP под выбранным именем после проверки всех снимков. Существующий файл назначения сохраняется.

## Consequences

Изображение можно выгрузить независимо от наличия точек. Экспорт с метками воспроизводим, исходный файл защищён от перезаписи, а полевой контекст не приходится хранить в имени файла или свободном комментарии к Analysis.
