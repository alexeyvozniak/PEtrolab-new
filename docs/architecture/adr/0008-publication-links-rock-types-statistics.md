# ADR-0008: Ссылки на публикации, Rock Type и статистика

- **Status:** Accepted
- **Date:** 2026-08-29

## Context

Хранение PDF каждой статьи необоснованно увеличивает проект. При этом Source должен оставаться воспроизводимой ссылкой на происхождение данных. Порода и статистический результат имеют самостоятельный научный смысл и не должны растворяться в полях Sample или компонентах интерфейса.

## Decision

Source-публикация хранит нормализованную библиографию, DOI и/или URL; локальный PDF не является обязательным и не входит в базовый контур Desktop v2.

Rock Type вводится как отдельная контролируемая сущность. Rock Assignment связывает Sample с Rock Type и хранит автора, метод, уверенность, основание и историю. Analysis получает явную область измерения, включая `whole-rock` и `mineral`.

Статистические операции выполняются отдельным application service и сохраняются как Calculation Run. Экран статистики является самостоятельным потребителем Selection, Work Group, Filter result или набора Samples/Rock Types.

## Consequences

Проект не превращается в хранилище статей, но сохраняет научную прослеживаемость. Названия пород можно исправлять и классифицировать без потери исходного текста. Статистические результаты воспроизводимы и не зависят от состояния виджета или текущей карточки объекта.
