# M2: пакетный импорт изображений и размещение точек

**Статус:** архитектурный контракт для утверждённых экранов импорта изображений  
**Дата:** 2026-08-30

## Утверждённый путь

`Файлы/папка → Sample и Thin Section → BSE/PPL/XPL/custom → ручное размещение → итоговая проверка → атомарное сохранение`.

Эталонами остаются `image-import-sample-assignment-v1`,
`image-import-manual-point-linking-v1`, `image-import-cross-sample-exception-v1`
и `image-import-final-review-v1`. Этот срез не меняет их визуальное решение.

## Границы

- Tauri выбирает один файл, несколько файлов или папку и передаёт Python только явный список путей.
- Python проверяет формат, размеры, SHA-256, назначения и геометрию и создаёт план без записи.
- React показывает план и preview, но не вычисляет координаты, fingerprints, дубликаты или межобразцовые правила.
- SQLite применяет подтверждённый план одной транзакцией. Копии файлов подготавливаются и проверяются до транзакции; при ошибке созданные копии удаляются.

## Поддерживаемый первый набор

- Растровые контейнеры: PNG, JPEG, TIFF и BMP.
- Научные типы: `BSE`, `PPL`, `XPL` и явный пользовательский тип.
- Источник: managed copy либо linked reference. Исходный файл не переименовывается и не изменяется.
- Пакет получает несколько путей за один вызов. Исполняемые `.bat` не являются изображениями и отклоняются как неподдерживаемый формат.

## Идентичность и связи

- Один физический файл определяется SHA-256 и хранится как один `Media Asset`.
- `Sample`, `Thin Section`, `Analytical Point`, `Analysis`, `Media Asset` и `Spatial Annotation` имеют устойчивые UUID.
- Analytical Point создаётся явной командой из двух или более существующих Analysis ID. Она не объединяет Measurements.
- Размещение хранит Point/Rectangle/Square в координатах исходного изображения, а не viewport.
- Связь Analytical Point с Spatial Annotation обратима. Удаление связи не удаляет ни один из связанных объектов.
- Несовпадение Sample изображения и Analytical Point требует непустой причины; исключение хранится в provenance связи.
- Совпадение Sample только фильтрует кандидатов. Автоматическая постановка точки запрещена.

## Команды

| Команда | Запись | Результат |
|---|---:|---|
| `analytical_point.create` | да | явно созданная Analytical Point и contributing Analysis IDs |
| `media.inspect_sources` | нет | форматы, размеры, SHA-256 и группы дубликатов |
| `media.import.plan` | нет | полный проверяемый план, предупреждения и semantic fingerprint |
| `media.import.apply` | да | Media Assets, Spatial Annotations и связи одной транзакцией |

`media.import.apply` повторно проверяет fingerprint каждого файла и semantic fingerprint плана. Изменённый файл, координата вне изображения, неизвестный ID, скрытый межобразцовый конфликт или дубликат с другим назначением блокируют запись.

## Release gate

1. Планирование не создаёт каталог media и не меняет SQLite.
2. PNG/JPEG/TIFF/BMP читаются без декодирования пикселей и без сторонней научной логики.
3. Пакет из нескольких файлов либо сохраняется целиком, либо не оставляет строк в базе.
4. Точка при любом zoom сохраняется в исходных пикселях и после повторного открытия совпадает.
5. Межобразцовое размещение без причины отклоняется.
6. SHA-256 исходников до и после операции совпадают.
7. Windows installer проходит smoke-test упакованного Python service.
