# Фото + диаграммы: MVP
Основание: согласованный пользователем экран; PR26, 5fb3a86. PR25 не объединяется.
## Цель и визуальная спецификация
Исследователь сопоставляет сохранённую метку фото с точными Analysis ID на 1–3 выбранных панелях.
В существующем окне построения включается режим «Фото + диаграммы»: слева от графиков фото с прежним MediaViewer, над ним выбор фото; под фото карточка связи. Справа остаются существующие панели, оси и настройки. При узком окне блоки переходят в одну колонку. Стиль, клавиатурные метки и координаты наследуются от существующего просмотрщика.
Основной путь: включить режим → выбрать фото из привязанных к входному набору → выбрать до трёх существующих панелей → нажать метку или точки графика → проверить все связи → явно добавить показанные ID в общий отбор.
Основное действие: «Добавить в отбор», с числом анализов. Фокус не меняет Selection.

При наведении мышью или фокусе с клавиатуры на индивидуальном маркере диаграммы или профиля показывается небольшой фрагмент оригинального фото вокруг сохранённой точечной метки `same_point`. В режиме «Фото + диаграммы» используется выбранное фото. Если точных меток несколько, подсказка сообщает об этом, а полное меню фото остаётся доступным. Контекстные связи не используются для центрирования фрагмента.
## Контракт
Ключи только media_asset_id, spatial_annotation_id, analytical_point_id, analysis_id; имена не используются для поиска. Несколько связей показываются все, без выбора первой. same_grain/same_zone/repeat_measurement обозначают контекст, а не доказанное место измерения. Геометрия всегда в исходных px.
Графики используют прежние проекции, оси, фильтры, слои и цвета. Фокус не снимает фильтры: часть ID может отсутствовать на графике.
Раскладка сохраняется новой Plot Specification v7 с photo_view (media_asset_id и panel_ids); старые версии читаются без изменений. Фокус и Selection не сохраняются как геометрическая истина. Удалённое фото вызывает явную ошибку, без подстановки.
## Состояния и приёмка
AT-PD1: фото → метка → все связанные ID подсвечиваются на выбранных панелях; общий отбор прежний.
AT-PD2: график → точные ID → все соответствующие метки выбранного фото; неоднозначность видна.
AT-PD3: карточка показывает Analysis ID, тип, Analytical Point, Annotation ID, x/y и размеры; связи зерна/зоны предупреждают о неточном месте.
AT-PD4: явное добавление объединяет ID с прежним отбором без дубликатов.
AT-PD5: сохранить/открыть возвращает фото и 1–3 панели, цвета/оси/слои/видимость сохранены.
Пустое состояние: нет связанных фото; загрузка: индикатор; ошибка: сообщение и повторное открытие; частичные данные: ID вне входа/фильтров явно остаются в карточке. Никакие действия этого режима не меняют исходные данные или связи.
## Следующий этап
Профили зональности: явный порядок точек/линия, калибровка px→мкм с provenance, выбор одного измерения при неоднозначности, расстояние–значение из Python core, разрывы для пропусков и отдельный экспорт связанной фигуры.
