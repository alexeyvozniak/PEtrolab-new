# UI Acceptance

## Правило приёмки

Пользователь принимает поведение приложения, а не реализацию. Каждый тест ниже выполняется на реальных данных или на фиксированном тестовом проекте и оставляет: автоматический результат, видео/лог при ошибке и скриншоты ключевых состояний.

## Условия провала

Тест считается проваленным, если приложение: теряет связь между точкой и источником; меняет исходные данные молча; показывает Selection как будто это сохранённая группа; меняет Selection при простом фокусе на Point; удаляет Source вместо обратимого исключения; использует скрытие на графике как QC-исключение; изменяет сохранённую легенду при Selection; удаляет исходный Media Asset при снятии связи; скрывает ошибку импорта; не открывает старый проект; или заметно расходится с утверждённым экраном.

## Формат отчёта QA

Для каждого изменения QA указывает: версию приложения, номер сценария, набор данных, результат, путь к скриншотам, найденные регрессии и вердикт `принято`/`не принято`. «Тесты прошли» без списка сценариев не является отчётом.
