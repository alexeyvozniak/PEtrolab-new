# Как пересчитать кальциевый амфибол

1. Импортируйте таблицу с измеренными SiO₂, MgO и CaO в wt.%.
2. В «Минералах» явно примите минерал либо назначьте его вручную с основанием.
3. Нажмите «Рассчитать формулу». Быстрый режим: 23 O, измеренное FeO/FeOt
   принято как Fe²⁺. Если Fe не измерено, это будет показано предупреждением.
4. Просмотрите APFU. При необходимости раскройте предупреждения, использованные
   измерения или «О методе».
5. Нажмите «Сохранить результат формулы». Он появится в «Сохранённых расчётах»
   и останется доступным после перезапуска.

Метод `amphibole.oxygen23/0.1.0` — черновой bulk-пересчёт Mg-Ca амфибола.
Он не выдаёт полную структурную формулу или определение вида.
Исходные числа сохраняются; сумма оксидов не приводится к 100%.

При ошибке PetroLab показывает конкретный компонент. Этот метод не поддерживает
измеренные F, Cl, H₂O, Fe₂O₃ и Fe₂O₃t, даже если их значение равно нулю.
Сохранение такого результата отключено. Не убирайте измеренные компоненты
из импорта, чтобы обойти ограничение метода.

При изменении параметра предпросмотр очищается. При изменении входных измерений
сохранённый расчёт показывается как устаревший; его прежние числа остаются
в истории, а новый расчёт сохраняется отдельно.
