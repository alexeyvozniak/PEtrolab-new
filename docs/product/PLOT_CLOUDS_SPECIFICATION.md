# Облака аналитических точек

## Цель и сценарий
Исследователь выделяет анализы, создаёт именованный слой из точного Selection и выбирает «Только облако выделения». На бинарной и тройной диаграммах строится существующая выпуклая оболочка по валидным координатам видимого входного набора. Слой сохраняет ID, а не зависит от последующего Selection. Несколько слоёв независимы; порядок слоёв определяет порядок наложения.

## Контракт версии 1
Существующее поле слоя получает необязательный style: {mode: outline|fill|both, color: #RRGGBB, fill_opacity: 0.05..1, stroke_width: 0.5..4}. Старое поле без style использует прежний зелёный контур/заливку. Прозрачность и размер маркеров независимы. Оформление не изменяет проекцию, Measurement, QC или координаты. Поля остаются геометрическим описанием, не вероятностной оценкой. Нормальный эллипс сохраняет прежний смысл.

При поле видимом, но недоступном (менее трёх неколлинеарных точек, неподдерживаемая панель) скрытые стилем слоя маркеры возвращаются на этой панели и выводится причина. Гистограммы остаются без полей и без скрытия слоем. Явное отключение поля и точек скрывает слой. Plot Visibility исключает анализы из входа поля; show_points=false — нет. По пересечению слоёв действует существующий порядок последнего слоя.

## Интерфейс
В существующем «Слои и поля» кнопка «Только облако выделения» создаёт именованный слой (введённое имя либо «Облако N»), включая выпуклую оболочку и отключая маркеры. Название показывает количество входных ID. Чекбоксы «Точки» и «Поле» остаются независимыми. Цвет, вид заливки, прозрачность, толщина доступны внутри поля. Слой можно удалить без удаления данных. Смена Selection не меняет его состав. Для новой группы создаётся новый слой.

## Сохранение и экспорт
Plot Specification v4 при наличии field.style; старые v1–v3 поддерживаются. Publication snapshot v4 хранит слои и точную геометрию, а SVG сохраняет fill=none для незакрашенного поля, stroke=none для заливки без контура. PDF использует существующий векторный pipeline. Отдельная сохранённая раскладка — долговременное хранение облаков. Геометрия сохраняется через projection fingerprint, стиль через definition/capture fingerprint. Изменение цвета не запрашивает расчёт геометрии.

## Приёмка
Выбрать 3 неколлинеарные точки → облако без маркеров → переключить контур/заливку → проверить SVG → восстановить раскладку. Проверить неподдерживаемую панель, малый набор, скрытые источники, отсутствие изменений отбора и исходных токенов, старые раскладки. Реальная визуальная проверка Windows обязательна.

## Следующие версии
Прямое создание облака из легенды минералов, физических образцов и Generation реализовано: фиксируется точный набор ID категории, цвет наследуется от категории, отбор не меняется. Создание напрямую из легенды источников, подписи полей и статистика группы остаются следующим этапом. Вогнутая оболочка/alpha shape — отдельный алгоритм с явно заданным масштабом, нормировкой пространства, обработкой разрывов и независимыми benchmark cases; без эвристического выбора параметра. Не реализовано в версии 1.
