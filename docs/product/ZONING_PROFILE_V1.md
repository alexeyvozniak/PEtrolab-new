# Профиль зональности v1

В режиме «Фото + диаграммы» пользователь выбирает по очереди сохранённые точки одного изображения, для каждой указывает Analysis ID, затем выбирает ось из существующих панелей и вводит длину отрезка в исходных пикселях и микрометрах. Таблица маршрута показывает порядок и позволяет переставить или убрать точки. Изменение маршрута, оси, фото или масштаба очищает устаревший результат.

В профиль входят координаты исходных пикселей только для `point` с активной связью `same_point` в том же образце. Выбор Analysis ID явный даже когда кандидат один. Привязка по зерну, зоне, повторному измерению, область или исключение между образцами не задают положение измерения.

Первая точка задаёт нуль. Длина каждого сегмента равна евклидову расстоянию между соседними точками, умноженному на отношение введённых мкм к px. Результат возвращает обе величины калибровки, версию метода, ось, ID аннотации и анализа, координаты, расстояние, значение и доступные сведения о его происхождении. Пропуск, цензура и неоднозначное значение оставляют разрыв. Повторное вычисление использует текущие сохранённые связи и проверяет их заново.

Профиль остаётся в сеансе просмотра. Сохранение маршрута, калибровка двумя кликами по масштабной линейке и экспорт фигуры относятся к следующему срезу.

Приёмка: маршрут (0, 0) → (3, 4) → (3, 7) при 2 мкм/px даёт 0, 10 и 16 мкм. Средняя точка без значения оставляет разрыв. Связь `same_zone` отклоняется. Смена фотографии очищает маршрут.
