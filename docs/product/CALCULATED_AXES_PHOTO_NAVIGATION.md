# Расчётные оси и связь фото–анализ–диаграмма

## Расчётные оси
Использовать существующие Python `sum`, `ratio`, `apfu` (версия 1), exact field/unit/method/measurement_set, provenance и exclusions. Конструктор внутри панели бинарной и тройной диаграммы заменяет выбранную ось. Измеренная ось доступна для возврата. APFU выбирает версию метода и конкретные Calculation Run IDs; при нескольких расчётах одного анализа не выбирается «последний» автоматически. В сохранённую раскладку/экспорт поступают существующие определения, без новых измерений. Mg# требует отдельного versioned molar method, явного FeO vs FeOt и независимых численных тестов. Не считать отношение массовых концентраций Mg#.

## Фото–Analysis–Plot
Источником связи служит analytical_point_analysis + analytical_point_annotation + spatial_annotation. Никаких совпадений по имени. Навигация не изменяет привязки, координаты исходных изображений, измерения или Plot Visibility. Переход из фото может добавить связанные активные анализы в общий Selection, затем открыть текущую раскладку, сохраняя входной набор (явно сообщить о точках вне области). Из диаграммы — показать все подходящие фото/аннотации, явно выбрать одно при неоднозначности. Профиль и одновременная подсветка нескольких точек — следующие этапы. 

## Gate
Тесты точного ключа, единиц, выбора APFU runs, отсутствия молчаливой подстановки. Интеграция с существующими scientific validation, layout, publication; визуальная приёмка и Windows CI обязательны.

### Реализация навигации, этап 1
Из контекстного меню анализа на диаграмме и в таблице открывается read-only диалог всех пространственных привязок по точному Analysis ID. При одном результате открывается фото, при нескольких — явный выбор. Масштабирование по координатам оригинала, проверка аннотации при загрузке, отметка типа связи и cross-sample exception. Галерея образца также показывает точки и привязки, клик по метке открывает инспектор. Кнопка перехода на диаграммы добавляет связанные активные анализы к отбору; текущая раскладка сохраняется, если все ID входят в её область, иначе открывается новая область по связанным ID. Одновременная подсветка всей выборки и профили зональности ещё не реализованы. Тест exact IDs/coordinates; native UI acceptance pending.
