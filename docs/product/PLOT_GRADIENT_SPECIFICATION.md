# Химический цветовой градиент — спецификация

## 1. Научный контракт
Окрашивание по отдельному измеренному параметру, независимому от осей. Выбор точного ключа field/unit/measurement_set/method из каталога; никакого смешивания ppm и wt.%, пересчёта железа, автоматической подстановки полей. Нули — числовые значения, <DL/квалифицированные значения, дубликаты, отсутствующие и нечисловые значения получают отдельные статусы. Разные reported_fe_form в одном ключе блокируют градиент. Python возвращает read-only payload, по каждому Analysis ID — значение, статус, исходные Measurement ID и токены. Фиксируется SHA-256 данных и определения. Лимит 50 000 анализов. Исходные измерения не изменяются.

## 2. Интерфейс (следующий этап)
В режиме «Окрашивание по составу» выбрать измеренное поле, линейную шкалу и цветовую палитру. По умолчанию диапазон min/max всего входного набора, независимо от текущего масштаба/отбора/скрытия маркеров. Постоянное значение — средний цвет. Неопределённые значения — нейтральные маркеры и счётчики причин, без замены нулём. Для чтения цветовой шкалы показывать название, единицу, метод/набор, минимальное/максимальное значение, число числовых/исключённых. Логарифмический режим и ручной диапазон после отдельных тестов. Гистограммы сохраняют исходное окрашивание. Градиент не меняет геометрию и выбор анализов.

## 3. Сохранение и экспорт (следующий этап)
Снимок раскладки/публикации хранит точный ключ поля, версию палитры, пределы шкалы, входные ID и fingerprint. Перед сохранением/восстановлением/публикацией проверять данные повторно, несовпадение явно блокировать. SVG: дискретная векторная цветовая шкала, без растра и SVG gradient, пригодная для CorelDRAW. Тесты: единицы, дубликаты, <DL, постоянный диапазон, отрицательные/экстремальные значения, воспроизводимость. В текущем коммите реализован только контракт получения значений; UI, сохранение и экспорт градиента ещё не реализованы.
