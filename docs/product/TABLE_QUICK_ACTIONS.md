# Быстрые действия таблицы

Кнопка «Копировать состав в Excel» в карточке и контекстном меню выгружает вертикальный TSV со всеми Measurement (включая повторные поля), исходными токенами, единицами, методом, набором, статусом, формой железа, идентификаторами и provenance. Копирование не зависит от отображаемых колонок и Selection. Формулоподобные текстовые поля экранируются для вставки в электронные таблицы; Excel может автоматически интерпретировать числовые строки, поэтому для точной долговременной передачи используется существующий XLSX-экспорт. Копирование адреса выгружает три столбца: сохранённое имя источника, лист, ячейка. Не угадывает путь к физическому файлу. При отказе буфера обмена — явная ошибка. Native UI acceptance required.

Закрепление: до трёх столбцов в указанном порядке после колонки выбора. Смещения рассчитываются по фактической ширине заголовков, пересчитываются при изменении ширины; скрытие колонки временно исключает её из закрепления. Старое сохранённое одиночное закрепление мигрирует в массив, локальная настройка сохраняется отдельно для UUID проекта. При узком окне пользователь может снять закрепление (автоматическое ограничение по ширине пока не введено). Проверка виртуальной таблицы 1000 строк и совместимости настроек.

## Быстрые действия диаграммы
Дублирование создаёт независимую копию определения панели с новым UUID рядом с оригиналом (оси, расчётные определения, нормировка, point_style). Общие слои/цветовая схема остаются общими, масштаб копии сброшен. До 32 панелей. Приближение выделения на бинарных и тройных диаграммах работает по всем видимым по слою маркерам выбранных ID, включая точки за границами текущего zoom; сохраняет аспект, ограничено 8×, имеет поля и сброс. Это экранное приближение, не смена научной шкалы и не обрезка экспорта. Тесты определения, viewport, сохранения отбора и панели. Нативная визуальная приёмка требуется.

## Пакетное оформление легенды
В текущей легенде выбор отдельных категорий либо всех, отдельные переключатели изменения цвета и символа (20 форм); для источников только цвет, без назначения символов на источник. Выбор оформления не меняет Selection, видимость, слои, вычисления. Ключи точные, отсутствующее значение не редактируется, другие режимы и невыбранные категории не затрагиваются. Цвет и символ сохраняются существующим явным действием «Сохранить цветовую схему проекта». Проверка ограничения 4000 записей, тесты merge/избирательности и интеграционный тест двух минералов с сохранением и без повторной проекции. Native QA pending.

## Импорт химических элементов без единиц
Использовать сохранённое suggested_target/suggested_canonical_field даже если список предупреждений отфильтрован. Явное исключение сохраняется. Показать количество распознанных компонентов без единицы; одна подтверждённая единица назначается только им внутри текущего блока. Нераспознанные поля и уже заданные единицы не меняются. Тест 15 элементов O…V, явно исключённое поле, неизвестное поле и La с ppm. Никакого угадывания wt.%/at.%/apfu. Windows QA pending.

### Много листов Excel
В пределах текущей книги показаны блоки с распознанными компонентами без единицы, включая неоткрытые листы. Выбор вручную, всех либо структурно идентичных активному блоку (точные заголовки/позиции, orientation, исходные роли, единицы, наборы и методы). Структурное совпадение не доказывает единицы: пользователь подтверждает явно. Назначение единицы формирует одну группу draft-решений, отправляемых существующим atomic mappings действием. Не трогаются исключённые блоки, вручную переопределённые поля, неизвестные заголовки, явные единицы. Регрессионный тест двух одинаковых листов, отдельного trace листа и отключённого листа. Полная нативная приёмка не выполнена.

### Отдельная строка единиц в многострочном заголовке
Распознаётся строго следующая за заголовком строка из явных единиц (не менее двух, допустимы пустые ячейки и метка Units), выровненных по непустым заголовкам, с последующей числовой строкой. Она не становится отдельным блоком/анализом. Единицы применяются к своим физическим столбцам; пустая единица остаётся на проверку, явная единица в названии поля имеет приоритет. Неизвестный текст и голый % не считаются доказательством. Не изменяются исходные токены и физические заголовки. Тест mixed wt.%/at.%/ppm/ppb и нерешённый Al. Сложные объединённые ячейки и конфликтующие явные подписи требуют отдельной проверки.

### Массовый метод и набор
Выбор включённых таблиц вручную/по одинаковой структуре/всех; отдельный фильтр единицы, только измерения с подтверждённой единицей. Заполняются пустые method и measurement_set независимо, уже введённые значения защищены; никаких догадок о методе, исходные токены не меняются. Сохранение через существующий batch mapping. Тест двух листов, исключённого блока, EPMA/WDS и trace. Нативная проверка pending.

### Локальные лабораторные шаблоны v1
Именованный шаблон из выбранного блока сохраняет физические заголовки, позиции, ориентацию, роли и канонические поля, подтверждённые единицы/метод/набор. Не сохраняет исходные значения, source/analysis IDs, решения о дублях, образцах или Fe. До 24 шаблонов на компьютере (localStorage), не синхронизируются между устройствами. Применение по строгому совпадению структуры и сопоставления; конфликт любого явно заданного unit/method/set блокирует весь блок. Ручной выбор совместимых блоков, заполнение только пустых свойств в черновике, обычное batch mapping для подтверждения. Не переносит вручную назначенную роль на нераспознанный заголовок; расширение совместимости и хранение в SQLite остаются отдельным этапом. Тесты чистой логики, хранения и конфликтов; реальная Windows приёмка обязательна.

### Единицы в транспонированных таблицах
Если компоненты расположены по строкам, соседняя колонка Units/Единицы (или пустой заголовок при строгом доказательстве не менее двух единиц) исключается из оси анализов; единицы читаются индивидуально по строкам. Пустые/неизвестные значения остаются нерешёнными. Конфликт явной единицы заголовка и соседней ячейки переводит компонент на ручную проверку в обеих ориентациях. Сохраняются физические координаты C2 и т. п. Первый этап: одна соседняя колонка единиц, не произвольные чередующиеся колонки или объединённые ячейки. Тесты транспонированного CSV, конфликтов и консервативного определения. Windows acceptance pending.
