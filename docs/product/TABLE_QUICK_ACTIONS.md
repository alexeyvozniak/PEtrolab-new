# Быстрые действия таблицы

Кнопка «Копировать состав в Excel» в карточке и контекстном меню выгружает вертикальный TSV со всеми Measurement (включая повторные поля), исходными токенами, единицами, методом, набором, статусом, формой железа, идентификаторами и provenance. Копирование не зависит от отображаемых колонок и Selection. Формулоподобные текстовые поля экранируются для вставки в электронные таблицы; Excel может автоматически интерпретировать числовые строки, поэтому для точной долговременной передачи используется существующий XLSX-экспорт. Копирование адреса выгружает три столбца: сохранённое имя источника, лист, ячейка. Не угадывает путь к физическому файлу. При отказе буфера обмена — явная ошибка. Native UI acceptance required.

Закрепление: до трёх столбцов в указанном порядке после колонки выбора. Смещения рассчитываются по фактической ширине заголовков, пересчитываются при изменении ширины; скрытие колонки временно исключает её из закрепления. Старое сохранённое одиночное закрепление мигрирует в массив, локальная настройка сохраняется отдельно для UUID проекта. При узком окне пользователь может снять закрепление (автоматическое ограничение по ширине пока не введено). Проверка виртуальной таблицы 1000 строк и совместимости настроек.

## Быстрые действия диаграммы
Дублирование создаёт независимую копию определения панели с новым UUID рядом с оригиналом (оси, расчётные определения, нормировка, point_style). Общие слои/цветовая схема остаются общими, масштаб копии сброшен. До 32 панелей. Приближение выделения на бинарных и тройных диаграммах работает по всем видимым по слою маркерам выбранных ID, включая точки за границами текущего zoom; сохраняет аспект, ограничено 8×, имеет поля и сброс. Это экранное приближение, не смена научной шкалы и не обрезка экспорта. Тесты определения, viewport, сохранения отбора и панели. Нативная визуальная приёмка требуется.
