# Domain Model

## Принцип

Сущности имеют самостоятельный научный смысл. Экран может показывать их по-разному, но не создаёт новый смысл данных. Интерфейс обращается к прикладным операциям, а не к таблицам базы напрямую.

## Базовые сущности

| Сущность | Смысл | Не является |
|---|---|---|
| Project | локальное исследовательское пространство, настройки и история | одним Excel-файлом |
| Source | происхождение данных: публикация, архив, лабораторный файл, полевая запись | только фильтром на графике |
| Import Batch | один зафиксированный запуск импорта с правилами и отчётом | Source целиком |
| Dataset Sheet | лист или логический набор внутри импорта | Sample |
| Sample | физический образец с устойчивым идентификатором | строкой анализа |
| Thin Section | шлиф, его изображение и пространственные аннотации | Sample, хотя может быть с ним связан |
| Spatial Annotation | физическая привязка на изображении шлифа: Point, Rectangle или Square с координатами и геометрией | Analysis, Media Asset или произвольной меткой на экране |
| Analytical Point | научная связь нескольких Analyses, относящихся к одной точке, зерну, зоне или повторному измерению | новым Analysis, средним значением или обязательной отметкой на изображении |
| Analysis | одна аналитическая запись/точка с идентификатором, методом и provenance | средним значением или графической точкой |
| Measurement | измеренное значение компонента с единицей, пределом обнаружения и статусом | автоматически пересчитанным значением |
| Derived Value | результат явного преобразования или расчёта | исходным измерением |
| Interpretation | научная классификация, комментарий или вывод пользователя | измерением или Derived Value |
| Mineral | контролируемая таксономическая сущность минерала | свободным текстом в строке |
| Generation | именованная проектная классификация происхождения/зоны анализа с владельцем и историей | цветом, фильтром или незафиксированной подписью |
| Selection | текущее эфемерное точное множество Analysis, выбранное пользователем | фильтром, поисковым запросом или Work Group |
| Work Group | сохранённое именованное множество Analysis с описанием, автором и временем создания | текущим Selection |
| Filter | обратимое правило видимости в конкретном контексте | удалением данных или Selection |
| Plot Specification | сохранённая настройка визуального представления: оси, стили, фильтры, слои | самим набором данных |
| Chart | созданное представление по Plot Specification и определённому входному набору | постоянной копией Analysis |
| Calculation Run | воспроизводимый запуск научного метода с входом, параметрами и версией | интерфейсной кнопкой |
| Media Asset | файл изображения/архива и его метаданные | Thin Section или Analysis |
| Media Link | обратимая связь Media Asset с Point или областью Spatial Annotation | перемещением или копированием медиафайла |
| Publication Package | экспортируемый набор графиков, таблиц, описаний и provenance | публикацией-Source |

## Ключевые отношения

- Project содержит Sources, Import Batches, Samples, Analyses, Work Groups, Plot Specifications и Calculation Runs.
- Import Batch создаёт или связывает Dataset Sheets, Sources и Analyses; все преобразования импорта фиксируются в provenance.
- Sample может иметь много Analyses, Thin Sections и Media Assets.
- Analysis принадлежит ровно одному первичному Source и может иметь дополнительные библиографические связи; содержит одну или несколько Measurements и Derived Values.
- Analysis может быть привязан к нулю или одному Sample и входить в ноль или несколько Analytical Points. Отсутствие связи не является ошибкой.
- Analytical Point связывает два или более Analyses устойчивыми идентификаторами, хранит тип связи и может ссылаться на ноль или одну Spatial Annotation. Одна Spatial Annotation может связывать несколько Analyses разных методов через Analytical Point.
- Spatial Annotation принадлежит одному Thin Section, хранит геометрию `point`, `rectangle` или `square`, координаты в системе изображения и, при калибровке, в системе шлифа.
- Media Asset может быть связан с нулём или несколькими Spatial Annotations через Media Link. Связь с Point или областью обратима и не изменяет исходный файл.
- Selection и Work Group содержат ссылки на Analysis по устойчивому идентификатору, а не по номеру видимой строки таблицы.
- Plot Specification ссылается на входной набор через Work Group, явно сохранённый список Analysis или список Analytical Points и хранит Filter как отдельную настройку представления. Для Analytical Point он также хранит источник каждого признака и явное правило разрешения повторов.

## Инварианты

1. `Selection` временный; его нельзя считать сохранённой выборкой.
2. `Work Group` сохраняет состав на момент создания. «Умные группы» на основе запроса могут появиться позже только как отдельный тип с явным снимком результата.
3. Выключение `Source` на графике создаёт/меняет только `Filter`; Source и его Analyses не удаляются.
4. `Generation` имеет проектный словарь значений, автора изменения и историю. Она не выводится автоматически из цвета или положения точки.
5. Каждое исходное значение имеет метод, единицу и provenance. `F не измерен` не равно `F = 0`.
6. Derived Value всегда хранит правило, параметры, версию алгоритма и ссылки на входные Measurement.
7. Фокус на Spatial Annotation не создаёт и не изменяет Selection. Добавление связанных Analyses в Selection является отдельным явным действием.
8. Точка, поставленная при большом увеличении, хранит исходные координаты, а не только положение текущего viewport.
9. Analytical Point не изменяет и не объединяет исходные Measurement. Построение по ней обязано хранить contributing Analysis ID для каждого показанного значения.
10. Несколько значений одного признака внутри Analytical Point требуют явного выбора Analysis или версионированного правила агрегации; молчаливое усреднение запрещено.
11. Автоматическая связь допустима только для однозначного составного ключа `Sample ID + normalized point name` и только по явно включённому правилу проекта/import recipe. Исходное имя, версия нормализатора, уверенность и история отмены сохраняются.
12. Похожее имя точки, совпадение имени в разных Samples или несколько кандидатов одного метода не создают Analytical Point автоматически.
13. Совпадение Sample у Media Asset и Analytical Point только сужает список кандидатов. Пространственное положение создаётся ручным действием пользователя; автоматическое размещение по имени или Sample запрещено.
14. Связь Analytical Point с изображением другого Sample допустима только после явного подтверждения и сохраняет признак исключения в provenance.

## Архитектурные границы

- **Scientific core:** доменная модель, валидация, расчёты, импортные преобразования, provenance, экспорт.
- **Persistence:** SQLite и миграции; хранит модель без знания о вкладках, виджетах и библиотеках графиков.
- **Application services:** операции `import`, `select`, `save_work_group`, `filter_source`, `build_chart`, `create_spatial_annotation`, `link_analysis_to_annotation`, `link_media_to_annotation`, `run_calculation`, `export_package`.
- **UI:** отображает состояние и вызывает application services. В UI не живут формулы, правила классификации или SQL-логика.
- **Desktop shell:** запуск, файловые диалоги, обновление, Windows-инсталлятор. Не владеет научными сущностями.
