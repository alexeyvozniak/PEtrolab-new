# Нормативный корпус реальных Excel для PetroLab

## Статус

Этот документ задаёт обязательный quality gate для импорта Desktop v2. Реальные исходные книги имеют приоритет над synthetic fixtures при оценке того, сохраняет ли PetroLab поведение на сложных научных данных.

## Нормативный набор v1

Реестр `fixtures/import/real-corpus.registry.json` содержит девять обязательных реальных книг. В него входят шесть исходных рабочих наборов, использованных при развитии импорта, и три реальные LA-ICP-MS книги 2026 года. Реестр фиксирует допустимые имена и назначение каждого regression case, но не содержит самих научных данных.

## Почему исходники не лежат в GitHub

`PEtrolab-new` — публичный репозиторий. Неопубликованные аналитические таблицы не должны становиться публичными только ради CI. Поэтому raw corpus хранится приватно и подключается к milestone/release-проверке через `PETROLAB_REAL_IMPORT_CORPUS_DIR` или `fixtures/import/real-private`.

## Что делает файл нормативным

Книга входит в normative corpus только если одновременно выполнены условия:

1. case зарегистрирован в `real-corpus.registry.json`;
2. присутствует точный raw workbook;
3. вычислен его SHA-256;
4. PetroLab прочитал книгу без изменения байтов;
5. создана candidate baseline;
6. состав листов, размеры, logical blocks и warnings проверены человеком/независимым verifier;
7. baseline явно переведена в `review_status: approved`.

Просто положить похожий Excel в папку недостаточно.

## Как обновлять corpus после найденного бага

Если дефект найден на существующей нормативной книге, сначала добавляется ожидаемое поведение/проверка, затем исправляется код. Если дефект найден на новой реальной книге, она регистрируется как новый обязательный case и проходит полную baseline-процедуру. При необходимости из неё дополнительно делается маленький synthetic reproduction для быстрого PR-CI, но именно реальная книга остаётся authoritative regression case.

## Gate перед выдачей milestone-сборки

```bash
python scripts/validate_real_import_corpus.py --require-all --corpus-dir fixtures/import/real-private
```

Milestone нельзя считать готовым, если команда не проходит на всех зарегистрированных книгах.
