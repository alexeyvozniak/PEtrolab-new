# Эталонные экраны PetroLab

В эту папку попадают только экраны, которые пользователь увидел и явно утвердил. Пока экран не утверждён, он хранится вне `reference/` как рабочий вариант.

## Именование

Для новых файлов используется `{screen}-{state}-{viewport}-{date}.png`. Имена `*-v1.png` сохранены для уже утверждённого первого набора, чтобы ссылки на них не менялись.

Примеры: `analyses-manual-selection-1440x900-2026-08-28.png`, `charts-source-filter-1280x800-2026-08-28.png`.

Рядом с каждым изображением должен быть Markdown-файл с:

- ID экрана и версией дизайна;
- назначением и состоянием;
- размером viewport;
- связанными US/AT-сценариями;
- кратким перечнем явно утверждённых решений;
- датой утверждения.

Эталон меняется только после нового пользовательского утверждения. QA использует эти файлы для визуального сравнения; они не являются декоративными иллюстрациями.
