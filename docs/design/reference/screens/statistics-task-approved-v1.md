## Назначение

Простой вход в статистику через понятный исследовательский вопрос и явный источник данных.

## Утверждённые решения

- Доступны задачи: описать набор, сравнить группы, проверить связь признаков и найти группы внутри набора.
- Selection, Work Group, Filter result или выбор позже не смешиваются и показаны отдельно.
- Последние Calculation Runs и черновик доступны справа, но не перегружают первый шаг.
- Формулы, названия тестов и параметры не показываются до выбора задачи.
- Каждый запуск создаёт Calculation Run и не меняет исходные Measurements.
