# Построение: слои и поля

- **ID:** `plotting-layers-fields`
- **Версия дизайна:** v1
- **Состояние:** утверждено
- **Viewport:** 1440 × 1024
- **Связанные сценарии:** US-22, AT-28
- **Дата утверждения:** 2026-08-29

## Назначение

Компактное управление сравниваемыми массивами Analyses внутри экрана «Построение» без превращения второстепенных настроек в отдельный тяжёлый режим.

## Утверждённые решения

- Раздел «Слои и поля» находится в левой панели и свёрнут по умолчанию.
- Для каждого слоя доступны быстрые переключатели видимости точек и Field, opacity и порядок.
- Все поля можно быстро показать или скрыть одним действием.
- Точки слоя можно скрыть, оставив рассчитанное по ним Field; это не равнозначно исключению Analysis из расчёта.
- Поддерживаются convex hull, доверительный эллипс и KDE-контур с видимыми методом и параметрами.
- Текущий Selection остаётся зелёным верхним слоем и не изменяет сохранённую легенду.
- Экспорт сохраняет видимые Field, порядок и прозрачность слоёв; эти параметры входят в Plot Specification.
