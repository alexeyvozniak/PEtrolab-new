# Analysis linking / automatic review v1

- **Статус:** утверждён пользователем, вариант 1
- **Дата:** 2026-08-29
- **Размер изображения:** 1487×1058
- **Сценарии:** импорт нескольких методов; автоматическая связка; проверка неоднозначных имён; переход к построению

Экран показывает общую очередь кандидатов после импорта. Таблица группируется по Sample и содержит нормализованное имя точки, исходные обозначения, отдельные Analyses EPMA/LA-ICP-MS/изотопии, уверенность и статус. Фильтры «Точные», «Проверить» и «Конфликты» не смешивают эти классы решений.

Правый инспектор раскрывает исходные Analysis, Source, лист, строку и объяснение совпадения. Автоматическая связь разрешена только для однозначного ключа `Sample ID + normalized point name`; похожие имена и несколько кандидатов одного метода требуют решения пользователя. Исходные Analyses остаются самостоятельными и связь обратима.

Основные действия: массово связать выбранные точные совпадения, перейти к следующему конфликту и открыть созданные Analytical Points в «Построении».
