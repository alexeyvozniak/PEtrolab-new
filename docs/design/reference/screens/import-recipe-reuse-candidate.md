# Повторное применение рецепта импорта

Статус макета — кандидат. Сценарии US-32 и AT-38. Контекст — утверждённый экран «Листы и колонки».

Пользователь добавляет книгу и выбирает сохранённую ревизию рецепта. До применения PetroLab показывает две книги, номер ревизии, версии схемы, смысловой отпечаток и отчёт совместимости. Под заголовком отчёта видны листы, строки заголовков, сопоставление полей и единиц, а также решение FeO/FeOt. Отдельный список содержит изменения при миграции, несовместимые и отброшенные поля.

Для совместимого рецепта действие «Применить к черновику» переносит решение в текущую книгу. Затем пользователь проходит обычную проверку импорта. Если требуется повторная проверка дубликатов, это действие открывает черновик с задачей «Проверить дубликаты». При несовместимости пользователь видит листы или решения, мешающие применению, и может вернуться к ручному сопоставлению. Отмена возвращает текущий черновик.

Приёмка использует исходную книгу из двух листов, совместимую книгу с новым значением и книгу с изменённой единицей в заголовке. Сверяются отчёт, целое сопоставление, исходные данные и сохранённая ревизия. Скриншоты фиксируют совместимый отчёт, обязательную повторную проверку и отказ.
