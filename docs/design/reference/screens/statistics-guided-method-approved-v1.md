# Статистика: пошаговый выбор метода

- **ID:** `statistics-guided-method`
- **Версия дизайна:** v1
- **Состояние:** утверждено как основное направление экрана
- **Viewport:** 1440 × 1024
- **Связанные сценарии:** US-12, US-23, AT-12, AT-29
- **Дата утверждения:** 2026-08-29

## Назначение

Пошаговая статистическая работа, начинающаяся с исследовательской задачи, состава входных данных и проверки применимости метода, а не с перегруженной панели статистических тестов.

## Утверждённые решения

- Последовательность: задача → данные → метод → результат.
- До расчёта видны точные группы, переменные, число Analysis, фильтры, исключения, пропуски и различающиеся аналитические методы.
- PetroLab может рекомендовать допустимый метод и объяснить основание, но пользователь подтверждает выбор сам.
- Расчёт создаёт новый Calculation Run и не изменяет исходные Measurements.
- Экран избегает лишних режимов и показывает только настройки, относящиеся к выбранной исследовательской задаче.
- Для задачи поиска структуры в одном наборе тот же помощник ведёт через выбор признаков и кластеризацию; результат можно явно сохранить как одну или несколько Work Groups.
