## Назначение

Проверяемый результат сравнения групп без автоматической геологической интерпретации.

## Утверждённые решения

- Violin/box/points и числовая таблица показывают один и тот же расчёт.
- Видны размеры групп, исключения, пропуски, mixed methods, test method, multiple-comparison correction и effect size.
- Статистическая значимость явно отделена от геологической значимости.
- Сохранить Calculation Run, вынести график, экспортировать таблицу и добавить в Publication можно отдельными действиями.
- Комментарий исследователя не меняет численный результат.
