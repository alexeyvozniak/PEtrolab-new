# Формулы минералов

- Статус: кандидат на утверждение
- Сценарии: AT-11, AT-31
- Точка входа: карточка Analysis

Пользователь открывает Analysis и выбирает «Рассчитать формулу». В рабочей области остаются видны ID анализа, источник и аналитический набор. Выбор метода показывает версию, кислородную основу, допущения о Fe и OH и список поддерживаемых компонентов. Рядом с методом доступна ссылка на публикацию.

Таблица входа содержит точные Measurement ID, компоненты, единицы и исходные токены. Подтверждённая поправка показывается в отдельной колонке с Operation ID. Пользователь выбирает один набор и по одному измерению на компонент. Последнее выбранное измерение не подменяет другое с тем же названием. При отсутствии нужного оксида, смешанных единицах, дублированном компоненте или значении ниже предела обнаружения таблица указывает строку и причину блокировки.

«Проверить вход» открывает отдельный блок APFU и показывает диагностические предупреждения. «Сохранить расчёт» создаёт неизменяемый результат после сверки отпечатков. Исходная таблица измерений остаётся доступной рядом. Для анализа без запусков показывается действие «Рассчитать формулу».

История показывает дату, версию метода и состояние каждого результата. При изменении входа или метода старый результат доступен с отметкой «Устарел» и причиной. «Пересчитать» возвращает к проверке текущего входа. Сохранение создаёт новый результат с собственным ID. Сравнение показывает значения APFU и входные токены обеих версий.

Приёмка использует опубликованный состав оливина из таблицы 1 Gündüz и Asan. Пользователь сохраняет первый запуск, подтверждает поправку MgO, открывает устаревший запуск и выполняет второй расчёт. Проверяются два отпечатка, обе версии результата, исходный токен в карточке и отсутствие изменения общего отбора. Состояние изменения версии метода проверяется с новой версией реестра. [Эталон APFU](https://doi.org/10.1180/mgm.2022.113).
