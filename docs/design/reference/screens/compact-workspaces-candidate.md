# Компоновка при ширине 390 px

**Статус:** кандидат на утверждение. **Сценарий:** AT-15.

Цель узкого вида — открыть раздел и выполнить его основное действие в пределах экрана 390×844. Научные данные, отбор, идентификаторы анализов и правила работы остаются теми же.

| Область | Предлагаемое поведение |
| --- | --- |
| Общая навигация | В заголовке остаются название раздела, кнопка открытия списка разделов и «Добавить данные». Меню разделов закрывается после перехода, по Escape и по кнопке закрытия. Фокус возвращается к открывшей его кнопке. |
| Обзор | Лента проекта показывается первой. План работы и рабочие группы следуют за лентой отдельными секциями. |
| Анализы | Таблица сразу видна под заголовком. Фильтры источников открываются по кнопке над таблицей, а подробности анализа доступны после выбора строки. Горизонтальная прокрутка действует внутри таблицы. |
| Поиск | Поля запроса переносятся в одну колонку. Результаты и сведения об источнике показываются последовательно. |
| Построение | Диаграммы идут в одну колонку. Раскладка, слои и окрашивание доступны из раскрываемой панели. Действия отбора переносятся по ширине. |

Проверка кандидата начинается с открытия каждого раздела и действия с клавиатуры. На 390×844 за границы страницы могут выходить содержимое таблицы в её собственном контейнере и увеличенная область диаграммы в её окне. Основные команды, статус и точка возврата фокуса должны быть доступны без горизонтальной прокрутки страницы. Параллельно проверяются настольные размеры из AT-15.
