# Статистика: результат кластеризации

- **ID:** `statistics-clustering-result`
- **Версия дизайна:** v1
- **Состояние:** утверждено
- **Viewport:** 1440 × 1024
- **Связанные сценарии:** US-23, AT-29
- **Дата утверждения:** 2026-08-29

## Назначение

Проверка результата кластеризации одного набора и явное сохранение выбранных вычисленных кластеров как обычных Work Groups.

## Утверждённые решения

- Кластеры одновременно видны на PCA-проекции и в табличной сводке.
- Для каждого кластера доступны точное число и список Analysis ID.
- Пользователь самостоятельно выбирает один или несколько кластеров, задаёт имена и сохраняет отдельные Work Groups.
- Шум и любой кластер можно не сохранять.
- Calculation Run сохраняет вход, признаки, масштабирование, алгоритм, параметры и исключения.
- Кластер не называется Generation или геологическим типом; смысл задаёт пользователь.
- Work Group является неизменяемым снимком состава и не пересчитывается молча после нового запуска.
