# Расчётные оси диаграмм

Статус — кандидат на расширение экрана «Построение». Связанные сценарии US-08 и US-16, проверки AT-07, AT-18, AT-27 и AT-31.

## Действия

1. На бинарной или тройной панели пользователь открывает список поля оси или вершины. В списке отдельно видны измеренные компоненты и доступные результаты расчёта формул. Для APFU рядом с названием показываются метод, версия и база нормировки.
2. Действие «Рассчитать компонент» открывает форму с выбором операции «Сумма» или «Отношение» и выбором входов. Формула и единица результата видны до применения. Для операции деления порядок числителя и знаменателя явный.
3. Для тройной панели проверяются совместимые единицы и научный смысл трёх компонентов. Результаты приводятся к долям от их суммы. Три согласованных безразмерных отношения допустимы, если относятся к сопоставимой базе. Несовместимая тройка блокируется с объяснением. Отдельное отношение можно использовать на бинарной панели.
4. Проекция показывает число включённых и исключённых анализов. Пропуск, `<DL`, неоднозначное измерение, недоступный расчёт, нулевой знаменатель, отрицательное значение для тройной панели и нулевая общая сумма отмечаются с причиной. Существующий отбор доступен в таблице.
5. В раскладке и пакете публикации сохраняются определения осей, исходные поля и единицы, привязка к версии расчёта формулы и её входам, правила преобразования и причины исключений. При изменении входа или метода интерфейс предлагает явный пересчёт.

Расчёт операндов, валидация и проекция выполняются в Python. Измеренные значения, токены и исходные файлы сохраняются.

Научный контракт версии 1 поддерживает три отношения с общим знаменателем и суммы неперекрывающихся компонентов. Для АФМ с уже измеренным FeOt используется эта форма железа. Преобразование другой формы Fe остаётся отдельной операцией с собственным определением. В Analysis Template версии 3 операнды сопоставляются по полю, единице, домену и аналитическому контексту. Для APFU пользователь отдельно подтверждает формулы нового набора. Экран выбора расчётных осей остаётся кандидатом.

Для APFU список формул сгруппирован по точному определению метода. Пользователь видит основу нормировки и выбирает один сохранённый расчёт на анализ. Три вершины используют один и тот же выбор расчётов. Если выбранные входы или метод устарели, возле анализа остаётся причина исключения, а выбор другого запуска требует явного действия.

## Примеры приёмки

- Пироксен: Mg–Fe²⁺–Ca на единой основе APFU. Независимый эталон с заранее рассчитанными компонентами проверяет проекцию и сохранение метода. Отсутствие согласованной формулы объясняется на панели.
- Отношение: La/Yb из концентраций одной аналитической серии с явным согласованием ppm и ppb. Проверяются положение контрольной точки на бинарной панели, нулевой знаменатель и `<DL`.
- Сумма: A = Na₂O + K₂O, F = суммарное железо в пересчёте на FeO, M = MgO из одного набора в массовых процентах. Проверить вклад каждого операнда, явный выбор формы Fe и отсутствие двойного учёта. Классификационная граница классической АФМ относится к сценарию валовой химии пород и требует отдельной приёмки применимости. [Полевой отчёт USGS с определением трёх компонентов](https://pubs.usgs.gov/of/1990/0316/report.pdf).
- Повторно открыть сохранённую раскладку и сравнить координаты, исключённые Analysis ID и подписанные оси. Сверить перенос этих данных в SVG и пакет публикации.
