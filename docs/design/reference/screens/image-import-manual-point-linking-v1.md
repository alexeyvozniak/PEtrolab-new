# Image import / manual point linking v1

- **Статус:** утверждён пользователем, вариант 1
- **Дата:** 2026-08-29
- **Размер изображения:** 1487×1058
- **Сценарии:** импорт изображения; назначение Sample; ручная привязка Analytical Point; большой zoom; выбор точки другого Sample

После назначения изображению Sample PetroLab показывает в первую очередь Analytical Points этого Sample. Пользователь выбирает точку, увеличивает изображение до нужного масштаба и вручную ставит Point либо создаёт Rectangle/Square. Пространственное положение не вычисляется автоматически и пользователь не работает с импортированными координатами.

До сохранения метка является предварительным положением. Команда «Сохранить привязку» создаёт обратимую связь; отмена или удаление связи не удаляют Analysis, Analytical Point или Media Asset.

Переключатель «Другой Sample…» открывает поиск по всем точкам проекта. Выбор точки, Sample которой отличается от Sample изображения, разрешён после явного подтверждения. Фокус на точке и её размещение не изменяют Selection автоматически.
