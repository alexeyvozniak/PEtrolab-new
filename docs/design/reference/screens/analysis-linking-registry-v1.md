# Analysis linking / registry v1

- **Статус:** утверждён пользователем, вариант 1
- **Дата:** 2026-08-29
- **Размер изображения:** 1487×1058
- **Сценарии:** проверка созданных Analytical Points; исправление связи; Selection; переход к построению

Реестр является основным состоянием после автоматической и ручной связки. Таблица показывает Sample, Analytical Point, тип связи, отдельные методы, число и идентификаторы исходных Analyses, изображение/координаты, время создания и статус. Фильтры доступны по Sample, методу, наличию изображения и числу Analyses.

Выбранная строка закрепляется и раскрывает исходные Analyses непосредственно под реестром. Правый инспектор показывает Source, лист, строку, тип связи и пространственную привязку. Пользователь может добавить Analysis, исправить состав или разорвать связь; разрыв никогда не удаляет исходные Analyses.

Нижняя полоса показывает одновременно число выбранных Analytical Points и исходных Analyses. «Построить диаграммы» открывает Plotting в явном режиме: одна точка является одним наблюдением либо каждый Analysis используется отдельно.
