- **Статус:** утверждён пользователем как состояние процесса

- **Сценарии:** итоговая проверка изображений, точек, Media Links и исключений

Перед транзакцией импорта пользователь видит каждый файл, Sample, Thin Section, тип, число размещённых Analytical Points, Media Links и межобразцовых исключений. Инспектор раскрывает устойчивые Analysis ID и размещённые метки.

Неразмещённые точки не блокируют импорт и не удаляются. Пользователь может вернуться к размещению, завершить без них или сохранить черновик. Завершение создаёт Media Assets и связи одной транзакцией; исходные файлы и Analyses остаются неизменными.
