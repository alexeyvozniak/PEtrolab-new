# Рабочие состояния и шаблоны анализа

Статус — кандидат экрана. Сценарий AT-33 и раздел 20.3 основной спецификации.

«Рабочие состояния» показывает сохранённые состояния проекта и состав выбранной записи. Перед открытием видны сохранённое представление таблицы, раскладки, видимость источников и активный расчёт. При сохранении пользователь выбирает, восстановить точный отбор или очистить его. Если часть состояния недоступна, отчёт указывает конкретное поле и причину.

«Шаблоны анализа» показывает схему колонок, оси и параметры метода. Пользователь выбирает новый набор и запускает проверку совместимости. Отчёт показывает требуемые и найденные единицы, а также фильтры исходного представления, которые не переносятся. После успешной проверки можно сохранить новое представление и раскладку. Для расчёта предусмотрено отдельное действие на подтверждённом наборе.

Для приёмки сохраняются таблица с колонкой Generation, три панели, видимость двух источников и кластеризация. После перезапуска сверяется полное состояние. Шаблон применяется к отдельному источнику в совместимых единицах. Для источника с ppm вместо массовых процентов отчёт показывает расхождение, и проект остаётся без новых таблиц, панелей и расчётов.
