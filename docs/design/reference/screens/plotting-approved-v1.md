# Plotting / approved v1

- **Статус:** утверждён пользователем
- **Дата:** 2026-08-28
- **Размер изображения:** 1487×1058
- **Сценарии:** US-08, US-16; AT-07, AT-18

Экран используется для интерпретации, а не как демонстрация. Он поддерживает 6, 8 и более панелей в прокручиваемой двухколоночной сетке: binary, ternary, spider, REE pattern, histogram. Rectangle/lasso на одном поддерживающем графике меняет общий Selection на всех панелях. Таблица доступна во вторичном нижнем dock.
