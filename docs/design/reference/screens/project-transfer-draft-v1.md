# Перенос проекта

- **Статус** · проект спецификации взаимодействия
- **Связанные сценарии** · US-27, AT-34, §20.3

В меню «Экспорт» утверждённого экрана «Обзор» действие «Архив проекта» предлагает сохранить базу, базу с исходными файлами или полную копию с изображениями. В диалоге указан состав выбранного варианта. Отмена возвращает пользователя в «Обзор».

Действие «Восстановить проект» открывает архив и после проверки показывает проект, уровень архива, будущий каталог и результат проверки. По умолчанию создаётся отдельный каталог. После успеха пользователь может открыть восстановленный проект.

Для замены отдельного закрытого проекта интерфейс показывает точный каталог назначения и место резервной копии. Замена требует отдельного подтверждения. При отказе исходный каталог остаётся доступен. При ошибке переключения интерфейс показывает результат отката и путь к резервной копии, если она осталась рядом с проектом.
