# Импорт изображений / назначение Sample — v2

- **Статус:** утверждён пользователем направлением продолжить следующий срез;
  реализован и проверен.
- **Дата:** 2026-09-23.
- **Эталон:** `image-import-sample-assignment-v2.png`.
- **Viewport:** 1363×936.
- **Сценарии:** AT-22, AT-23; одиночное назначение, массовое назначение,
  проверка дубликатов и переход к ручному размещению точек.

## Утверждённые решения

- На шаге назначения остаётся один список изображений; отдельная левая очередь не
  повторяет ту же информацию.
- В строке счётчиков всегда видны пакет, готовые, требующие проверки и дубликаты.
  «Требуют проверки» и «дубликаты» фильтруют единственный список.
- Инспектор справа редактирует выбранное изображение и содержит ясное действие
  «Подтвердить это назначение».
- Массовая панель с «Подтвердить предложения» и «Применить к выбранным» показана
  только при двух или более отмеченных строках.
- Добавление файлов и папки доступно в общей верхней панели один раз; локальные
  дубли этих действий отсутствуют.
- В нижней панели одно главное действие «Продолжить: точки». Пока нельзя перейти,
  рядом видна конкретная причина. Сообщение о сохранности исходных файлов показано
  там же, без повторов в остальных панелях.
- Подтверждение, типы BSE/PPL/XPL, блокировка дубликатов, storage mode и отсутствие
  записи в исходные файлы сохраняют поведение v1.
