# Кандидат: библиотека сохранённых изображений v1

Статус: кандидат для согласования перед production-компоновкой  
Дата: 2026-09-23  
Срез: 3 — библиотека сохранённых изображений

## Назначение

После импорта и повторного открытия проекта пользователь видит сохранённые изображения как библиотеку, а не пустой старт мастера. Экран помогает найти файл по имени или образцу и честно сообщает, когда внешний источник больше недоступен. В этом срезе нельзя редактировать метки, сравнивать изображения или менять источник.

## Компоновка

```text
Изображения · 12                                      [Папка] [Добавить изображения]
──────────────────────────────────────────────────────────────────────────────────
[Поиск по имени…                         ] [Образец: все ▾]     12 результатов

Имя                 Образец / шлиф       Тип · размер       Метки       Хранение
KIV-2_BSE_01.png    KIV-2 · KIV-2-TS1    BSE · 2048 × 1536  3           В проекте
KIV-2_XPL_01.png    KIV-2 · KIV-2-TS1    XPL · 2048 × 1536  0           Внешний файл недоступен

Внешний файл недоступен. Запись и её связи сохранены; восстановите файл по прежнему
пути, чтобы открыть его. Редактирование и повторное указание пути — следующий срез.
```

Один полноширинный список — без постоянного инспектора и миниатюр. Выбор строки только обозначает фокус; действие «Открыть» появляется в срезе 4, когда оно действительно показывает сохранённые метки. Главный вход для добавления файлов остаётся в глобальной шапке.

## Данные и состояния

- Список строится из `media_asset` проекта, а не из незавершённого пакета импорта.
- Поиск работает только по отображаемому имени; фильтр образца — точное значение из списка проекта.
- Для `managed_copy` показывается «В проекте», если файл находится в папке проекта; его отсутствие — отдельный технический статус без раскрытия пути.
- Для `linked_external` доступность проверяется при открытии библиотеки. При отсутствии показывается понятное объяснение выше, без ложного действия исправления.
- Счётчик «Метки» — число сохранённых пространственных аннотаций, не число выбранных точек.

## Приёмка среза

1. После применения импорта и повторного открытия проекта библиотека возвращает те же медиа-ID и имена.
2. Поиск по имени и фильтр образца не меняют БД.
3. Удалённый внешний файл остаётся строкой библиотеки со статусом «Внешний файл недоступен»; исходный путь не выводится.
4. Нет canvas-редактора, сравнения, переназначения источника или записи координат.
