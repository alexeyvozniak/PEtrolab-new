# Рабочие состояния и шаблоны

- **Статус** · проект спецификации взаимодействия
- **Связанные сценарии** · US-26 и AT-33

В «Обзоре» карточка «Продолжить работу» показывает сохранённое рабочее состояние, его название и последний активный раздел. Действие «Открыть» сначала проверяет доступность представления таблицы, раскладок, источников, Analysis ID и расчёта. При несовместимости карточка показывает отчёт и сохраняет открытое рабочее состояние.

Форма сохранения рабочего состояния показывает состав снимка. Политика отбора выбирается явно: восстановить точный отбор или открыть состояние с пустым отбором. После восстановления приложение открывает сохранённый раздел.

При сохранении шаблона пользователь выбирает представление таблицы, раскладку, статистический метод или их сочетание. Подсказка сообщает, что фильтры исходного представления не переносятся. При применении пользователь выбирает новый набор анализов и получает отчёт совместимости. Совместимые представление и раскладка сохраняются вместе. Параметры статистики открываются в разделе «Статистика» с результатом проверки входа. Расчёт запускается отдельной кнопкой.
