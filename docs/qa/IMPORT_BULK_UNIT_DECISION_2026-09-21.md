# Один вопрос о единице для повторяющейся Excel-структуры

Проверка относится к import workspace из ADR 0014 и AT-02/AT-03. Это не
изменяет исходный Excel, научные правила, формулы или provenance.

## Исходная проблема

`fixtures/import/real-world/mica+Chl_all_zond.xlsx` содержит три одинаково
распознанных блока с 48 полями без явно указанной единицы. Сервис уже выдавал
одну безопасную область массового решения, но не связывал с ней вопросы
session review. Поэтому интерфейс показывал три повторяющиеся группы и 48
индивидуальных карточек, а производный `IMPORT_PLAN_EMPTY` выглядел как ещё
одно обязательное решение.

## Принятое поведение

- Python связывает каждую физическую ошибку единицы с выданным им
  `bulk_scope_id`; React не определяет похожесть полей самостоятельно.
- По умолчанию виден один вопрос: «Какая единица у этих измерений?» и одна
  кнопка, применяющая ответ только к этой проверенной области.
- Кнопка «Настроить поля по одному» остаётся явным выходом для смешанных
  единиц.
- Пока есть реальные нерешённые сопоставления, `IMPORT_PLAN_EMPTY` является
  объясняющей информацией, а не отдельным обязательным действием. Если после
  их устранения план по-прежнему пуст, он снова блокирует импорт.

## Нативная проверка (1363×936)

1. Открыт реальный `mica+Chl_all_zond.xlsx` в Tauri Desktop.
2. До решения видны исходная таблица, один вопрос для 48 полей, выбор единицы
   и действие «Назначить 48 полям»:
   [`import-bulk-unit-guided-1363x936-20260921.png`](screenshots/import-bulk-unit-guided-1363x936-20260921.png).
3. Выбрано `wt.%` и применено массовое решение. Группа исчезла, столбцы
   показывают `wt.%`, а следующее независимое препятствие осталось видимым:
   [`import-bulk-unit-applied-1363x936-20260921.png`](screenshots/import-bulk-unit-applied-1363x936-20260921.png).
4. SHA-256 исходника до и после: `81C6978D9893DA92F4FE9E32F651CA05C2A170339C8040E2DA96E8BBECF1745B`.

## Автоматические регрессии

- Python: одна server-issued область связывает два unit issue; ответ делает
  план готовым, не меняя bytes CSV.
- UI integration: одна область из двух полей — одна карточка и один запрос
  `apply_bulk_decision`; источник не меняется.
- UI E2E и Tauri shell contract проверяют targets области и новую
  пользовательскую формулировку.

## Незакрытое наблюдение

После решения единиц этот реальный файл показывает отдельную ошибку
`ANALYSIS_IDENTITY_REQUIRED` для строки 37. В данном срезе она намеренно не
скрывалась и не исправлялась: это независимая задача по объяснению/исправлению
пустой идентичности или границ блока, а не вопрос единиц.
