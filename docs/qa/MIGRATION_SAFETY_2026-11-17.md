# Проверка защиты проектов и миграций

Область: Python core и упакованный научный сервис; визуальная приёмка и проверка установщика на чистой Windows в этот отчёт не входят.

- Миграция заполненного старого тестового проекта сохраняет строки и создаёт SQLite backup.
- Искусственная ошибка после DDL откатывает эту миграцию вместе с записью в истории; исходные строки и backup сохраняются, `integrity_check` возвращает `ok`.
- Более новая миграция, версия метаданных выше истории, посторонняя непустая база и непустая база с пустой историей отклоняются без изменения байтов базы.
- Упакованный сервис импортирует восемь анализов из фиксированного Excel во временную базу, восстанавливает результат после перезапуска и сохраняет SHA-256 источника; отказывает при открытии несовместимой и посторонней базы без записи.
- MSI и NSIS пересобраны; при административной распаковке MSI SHA-256 вложенного сервиса совпал с проверенным бинарником. Это не проверка установки.
- Сбой миграции передаёт через протокол `PROJECT_MIGRATION_FAILED`, имя миграции и путь к backup. Упакованный сервис также проверен на `<1e-3` и `<1e-999`: исходные токены и статус сохраняются, непредставимый предел не становится нулём.
- Входной контроль минеральных предложений версии `import-wt-percent-complete-core-2` отклоняет ненулевой токен, который при преобразовании в float стал бы нулём; старые подтверждения не считаются актуальными при новом fingerprint. Проверено в Python и в упакованном сервисе.
- Автоматические проверки: `python scripts/validate_contracts.py`, 139 Python tests, 9 UI tests, 20 Tauri contract tests, 4 Sites tests, `cargo check --offline`, web build и `python scripts/qa_packaged_import.py` прошли.

Ограничения: транзакция относится к отдельной миграции, а не ко всей цепочке; восстановление до начала обновления требует backup. Полный AT-13 с приёмкой в приложении, AT-14 на чистой Windows и визуальное сравнение не проведены. Остальные разделы и весь план из 20 срезов не считаются завершёнными.
