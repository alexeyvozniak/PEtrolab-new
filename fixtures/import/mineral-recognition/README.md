# Независимые данные для проверки распознавания минералов

Три небольшие выборки используют опубликованные метки фаз и отдельные колонки оксидов в массовых процентах. Точки и средние по нескольким измерениям сохраняются в отдельных файлах. Составы перенесены с опубликованной точностью. Десятичная запятая преобразована в точку там, где это нужно для CSV. Маркер `bdl` и исходное обозначение суммарного железа `FeOt` сохранены.

- `bec-dovaga.csv` содержит точки BO1-ol-1 и BO1-ol-4 из микрозондовой части приложения. [Sulfur and metal fertilization of the lower continental crust, приложение A2](https://ntrs.nasa.gov/api/citations/20180001951/downloads/20180001951.pdf).
- `mount-agri.csv` содержит три точки из второй фазы Mount Ağrı. Названия объединяют образец и точку из шапки таблицы. [Determination of the P-T conditions and depths of magma storage zones, таблица 5](https://pmc.ncbi.nlm.nih.gov/articles/PMC12755766/#Tab5).
- `epma-averages.csv` содержит средние из колонок Gabbro, Pl OlWeb и OlWeb. Названия объединяют колонку и сокращение фазы. [Journal of Petrology, таблица 1](https://academic.oup.com/view-large/352439995).

Контрольный сценарий сравнивает предложенные группы с опубликованными метками. При перекрывающихся признаках он требует показать конкурирующие кандидаты и оставить назначение открытым. Для `bdl` он проверяет сохранение статуса ниже предела обнаружения и отказ от предложения. Покрытие ограничено перечисленными группами и сценариями.
